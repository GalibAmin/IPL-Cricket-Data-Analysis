# IPL Cricket Data Analysis

An IPL data analysis project using Python, SQL, SQLite and Tableau to explore match trends, team performance, toss decisions, top run scorers, wicket-takers and venue statistics.

### Dashboard

[View the interactive IPL dashboard on Tableau Public](https://public.tableau.com/app/profile/galib.amin/viz/IPLAnalyticsDashboard_17932675859820/Dashboard1)

### Tools Used
- Python, Pandas, NumPy
- SQL and SQLite
- Google Colab
- Tableau Public

### Project Files
- `IPL_Cricket_Data_Analysis.ipynb` — analysis notebook
- `tableau_exports/` — CSV files used for the dashboard

### Key Analysis
- Matches played by season
- Team wins and win percentages
- Toss decisions
- Top 10 batters and bowlers
- Venue-wise first-innings scores
- Run rate by match phase
- Orange Cap and Purple Cap trends

### Dataset
Cricsheet data sourced via Kaggle. Please refer to the original dataset page for its licence and usage terms.
