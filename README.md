# 🏏 IPL Cricket Data Analysis & Analytics Dashboard

An end-to-end IPL analytics project combining **Python, SQL, SQLite, data analysis, and Tableau** to explore team performance, toss decisions, batting and bowling records, venue statistics, and season-wise trends.

## 📊 Live Dashboard

**[View the Interactive IPL Analytics Dashboard on Tableau Public](https://public.tableau.com/app/profile/galib.amin/viz/IPLAnalyticsDashboard_17932675859820/Dashboard1)**

## 🎯 Project Objectives

- Analyze IPL match and season trends.
- Compare team performance and win percentages.
- Investigate toss decisions and match outcomes.
- Identify leading run scorers and wicket-takers.
- Explore venue statistics and scoring patterns.
- Present key findings through an interactive Tableau dashboard.

## 📈 Dashboard Analysis

The dashboard covers:

- **Season Trends:** IPL matches by season.
- **Team Performance:** Win percentages and matches won.
- **Toss Analysis:** Bat-first versus field-first decisions.
- **Batting Performance:** Top run scorers and Orange Cap trends.
- **Bowling Performance:** Top wicket-takers and Purple Cap trends.
- **Venue Analysis:** Average first-innings scores by venue.
- **Scoring Trends:** Run rate across match phases.

## 🚀 How to Explore the Project

1. Open `IPL_Cricket_Data_Analysis.ipynb` in Google Colab or Jupyter Notebook.
2. Ensure the required source dataset is available in the notebook environment.
3. Run the notebook cells in order to reproduce the analysis.
4. Review the exported CSV summary tables in `tableau_exports/`.
5. Open the published Tableau dashboard using the link above.
